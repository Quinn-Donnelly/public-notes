First interesting insight that I wasn’t aware of is that CanvasItem is actually the direct descendent of Node and Node2D is a CanvasItem1

All CanvasItems are children of some direct or indirect viewport. The Transform is the position that Camera operate on.

The default scene tree in GoDot renders on layer 0. CanvasLayer have a number for their layer. Higher numbers are drawn on top the lower. CanvasLayers set the layer for their children and grand children.23

Input events have transforms based on the viewports transform and are not local coordinates to the CanvasItem the helper function CanvasItem.make_input_local(InputEvent) is a function to convert the Input Transform2D to the local cords.

root viewport is Window it’s rendering job is those black bars that cause the aspect ratio to be able to stay fixed.

There are four coordinate systems at play that a Transform2D will deal with4

  1. local coordinates on the CanvasItem
  2. canvas coordinates on the CanvasLayer
  3. viewport coordinates of the game world - of which a Camera2D determines which parts of it are viewable
  4. Window coordinates on game screen
