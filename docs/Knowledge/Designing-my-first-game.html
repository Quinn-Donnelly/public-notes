    Designing my first game

    Designing my first game

    Apr 18, 20254 min read

    Core Game Idea

    Thinking I should do the Phasebound idea which was recorded in the game idea platformer but as Minato the core mechanic I should build around first is the rewind. Due to the fact that I understand the data structure involved and I have worked quite a bit in the space of positioning data.

    Things to do for it

    • create a world scene with a couple of platforms in it
    • create a player and controls that let a character go up, left, right, for now don’t worry about the whole down jump through platform or slide mechanic
    • build up the rewind mechanic get it functional
    • build a visual for the rewind location
    • build the throwable item system

    Once this is done I’ll want to play around with teleporting around using the daggers. But first should determine how the feel is on the above. there is a solid chance that it feels good enough I should just build a base game around the rewind mecanic. There are a few level design ideas I have.

    Level Design Ideas

    1. Drop into an area that has no way to get back up other than your rewind

    2. Time based pickup where you grab a melting object that you need to get back to some delivery point in an amount of time that won’t let you get there. So you have to actually race there the other way and then use the rewind - I may need the slide mecanic for this to have the slope direction be the reason you can’t get back the other direction.

    Implementation

    Putting platforms in the world going to ignroe the need of art for now will just use colored meshes to see for now

    I have a world with a platform now for a player character, due to animation reasons I should likely grab asset at least for the character will use Kenny nl free 2d art to do that.

    Todo

    • Fix the floaty jump / character control
      • Player controller changed to state machine
      • jump input buffering
      • custom jump curve (fall faster)
      • Variable jump height
      • check if coyote time is needed
      • Maybe ease in gravity
    • Collectible that calls add score
    • Scoring will need to be a component and we will need to have a “collect” call that tracks the number of collectibles gathered so we can mult them? This will aid with future if I have a bonus that’s like perfect pick up
    • phase out the old objects and markers to clean the interface a bit
    • The logic for rewind works but could be cleaned up into a component
    • Add a cooldown to the rewind ability
    • Likely need to tune the recording of locations to pause when you use the rewind ability
    • Build out a level to actually test the platformer mechanic
      • Platform builder using Tilesets
      • Camera / level mover
      • A way to win

    Improvement Ideas

    • I wonder if the feeling would be better if I instead of having jump velocity applied each frame I instead held off gravity did a big impulse at the start of the jump then when button release or max I start to apply gravity?

    Slow Downs

    • I don’t seem to recall how to put color on a mesh in a 2D game
    • I think learning tilemaps for 2D platform game would make sense
    • I need to learn how to make the character falling a bit snappier it’s very floaty right now, I’m thinking acceleration of gravity on a curve like an ease
    • I don’t know the built in data structure of GoDot, nor the type system well
      • I don’t know how to do a template function so type safety goes away on my helper classes
      • Working with classes, I recalled that ever script is one but was unaware of how to load and instantiate a new class
      • Need to figure out what the equivlant of the stringer or toString would be in this language
    • template strings I only know how to do one level deep
    • Need to learn truly what goes in _process as right now I see too much as being physics based
